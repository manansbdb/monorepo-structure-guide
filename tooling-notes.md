# Tooling Notes / Notas de Tooling

## English
- Pin Node and package manager versions (`.nvmrc`, `packageManager`).
- Use a task runner (Turborepo/Nx) for affected builds/tests.
- Keep shared configs in packages (`eslint-config`, `tsconfig`).
- Define CODEOWNERS per app/package path.

## Português
- Fixe versões de Node e package manager (`.nvmrc`, `packageManager`).
- Use um task runner (Turborepo/Nx) para builds/testes affected.
- Mantenha configs partilhadas em packages (`eslint-config`, `tsconfig`).
- Defina CODEOWNERS por path de app/package.
